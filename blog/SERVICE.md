# blog

Модуль `micro/blog`. Владелец таблицы `posts`.

## Назначение

Статьи: чтение публичное, запись только по access-токену. Править и удалять
статью может лишь её автор.

Секрет подписи JWT сервису неизвестен и токен он не разбирает: каждый
защищённый запрос идёт в `auth` по gRPC (`ValidateToken`). Поле `posts.author_id`
ссылается на пользователя чужого сервиса и **без foreign key** — таблицу `users`
blog не трогает.

## Запуск

```sh
make up
make migrate
cp blog/.env.example blog/.env && set -a && . blog/.env && set +a
go run ./blog
```

Сначала должен быть поднят `auth` — без него защищённые маршруты отвечают 503.

## Переменные окружения

| Переменная | Назначение | По умолчанию |
|---|---|---|
| `LOG_LEVEL` | debug / info / warn / error | `info` |
| `ENVIRONMENT` | Метка окружения в метриках | `local` |
| `REST_PORT` | Порт REST-API | `8082` |
| `METRICS_PORT` | Порт `/metrics` для Prometheus | `9102` |
| `POSTGRES_DSN` | Строка подключения | обязательна |
| `POSTGRES_MAX_CONNS` | Верхняя граница пула | `10` |
| `POSTGRES_MIN_CONNS` | Тёплые соединения | `2` |
| `AUTH_GRPC_ADDR` | Адрес gRPC сервиса auth | `localhost:9091` |

## Контракт

| Метод | Путь | Доступ | Ответ |
|---|---|---|---|
| GET | `/posts?limit=&offset=` | публично | `200 [{post_id, author_id, title, body, created_at, updated_at}]` |
| GET | `/posts/{id}` | публично | `200 {post_id, ...}` |
| POST | `/posts` | токен | `201 {post_id, ...}` |
| PUT | `/posts/{id}` | токен, только автор | `200 {post_id, ...}` |
| DELETE | `/posts/{id}` | токен, только автор | `204` без тела |
| GET | `/healthz` | публично | `200 {status, service}` |

Тело на запись: `{"title": "...", "body": "..."}`. Автор берётся из токена, в
теле его передавать нельзя.

`limit` по умолчанию 20 и ограничен сверху 100, `offset` меньше нуля считается
нулём. Список отсортирован по `created_at` убыванием.

Ограничения: заголовок до 200 символов, тело до 20000. Пробелы по краям
обрезаются, строка из одних пробелов считается пустой.

## Коды ошибок

| Код | HTTP | Когда |
|---|---|---|
| `64c4a693-001` | 400 | Тело запроса не разобрать |
| `64c4a693-002` | 400 | Нет обязательного поля |
| `59831142-001` | 400 | `{id}` в пути не UUID |
| `59831142-002` | 400 | Заголовок пустой |
| `59831142-003` | 400 | Тело статьи пустое |
| `59831142-005` | 400 | Заголовок длиннее 200 символов |
| `59831142-006` | 400 | Тело длиннее 20000 символов |
| `42601feb-001` | 400 | `limit` или `offset` не число |
| `cce2da53-001` | 400 | Пустой запрос в юзкейс |
| `cce2da53-002` | 400 | Не передан postID |
| `64c4a693-003` | 401 | Нет заголовка `Authorization: Bearer` |
| `2564e485-030` | 401 | auth отверг токен |
| `42601feb-002` | 401 | Запрос дошёл до ручки без опознанного вызывающего |
| `cce2da53-030` | 403 | Статья принадлежит другому автору |
| `cce2da53-020` | 404 | Статья не найдена |
| `2564e485-040` | 503 | auth недоступен |

В таблице только то, что клиент может увидеть при нормальной работе. Остальные
коды сервиса наружу приходят как 500, потому что означают сбой, а не исход
запроса:

- `6dadc350-*` — ошибки репозитория, включая `6dadc350-020`: строка исчезла
  между чтением и записью
- `cce2da53-010` — обёртка над упавшей операцией
- `cce2da53-003` и `59831142-010..013` — незаполненные поля в Builder и юзкейсе.
  До них можно дойти только багом в вызывающем коде: валидация стоит раньше

## Проверка

```sh
curl localhost:8082/healthz

TOKEN=$(curl -s -X POST localhost:8081/auth/login -H 'Content-Type: application/json' \
  -d '{"email":"a@b.c","password":"correct horse battery staple"}' \
  | python3 -c 'import sys,json;print(json.load(sys.stdin)["access_token"])')

curl -s -X POST localhost:8082/posts -H "Authorization: Bearer $TOKEN" \
  -H 'Content-Type: application/json' -d '{"title":"Первая","body":"Текст"}'

curl -s localhost:8082/posts
curl -s -o /dev/null -w '%{http_code}\n' -X POST localhost:8082/posts \
  -H 'Content-Type: application/json' -d '{"title":"x","body":"y"}'   # 401
```
